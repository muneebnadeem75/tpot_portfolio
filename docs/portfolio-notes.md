# Portfolio Notes

## What this repository represents

This repository is a public, sanitised presentation of an academic T-Pot honeynet investigation. The original work involved Google Cloud infrastructure, distributed sensors, Kibana analysis and investigation of captured attack activity.

## What is intentionally not included

- Google Cloud credentials
- SSH private keys
- API credentials
- Live cloud infrastructure addresses
- Student number / university identifier
- The original 34-page university submission
- Raw honeypot logs that could expose unnecessary infrastructure or third-party data

## Reproducibility

The original deployment depended on cloud infrastructure and a live Internet-facing honeynet. This portfolio repository documents the architecture, investigation methodology and findings rather than providing a turnkey public honeypot deployment.
